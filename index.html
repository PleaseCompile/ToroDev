สิ่งที่ ไม่รวม คือค่าโดเมนกับค่าโฮสติ้ง (จ่ายตามจริงกับผู้ให้บริการ ประมาณ 1,000–2,500 บาท/ปี) และค่าถ่ายภาพ/ซื้อภาพสต็อก ถ้าคุณมีโฮสต์อยู่แล้วเราขึ้นให้ที่เดิมได้เลย

Landing Page ประมาณ 7–10 วัน · เว็บบริษัท 2–3 สัปดาห์ · E-Commerce 4–6 สัปดาห์ · ระบบ ERP/CRM 8–16 สัปดาห์ ขึ้นกับขอบเขต

ตัวแปรที่ทำให้ช้าที่สุดคือการรอเนื้อหาจากฝั่งลูกค้า ถ้าเตรียมข้อความกับรูปไว้พร้อม งานจะจบเร็วกว่าที่ประเมินไว้เกือบทุกครั้ง

อย่างน้อยที่สุด: ชื่อธุรกิจ · สิ่งที่ขาย · กลุ่มลูกค้า · ช่องทางติดต่อ · โลโก้ (ถ้ามี) · รูปสินค้าหรือรูปหน้างาน

ถ้ายังไม่มีข้อความ เราช่วยร่างให้ได้ และถ้ายังไม่มีโลโก้ เรารับออกแบบให้เริ่มที่ 4,500 บาท ไม่ต้องรอให้พร้อมทุกอย่างก่อนค่อยเริ่มคุย

งานทั่วไปแบ่งเป็น 2 งวด — มัดจำ 50% ตอนเริ่ม และอีก 50% ตอนส่งมอบ

งานที่เกิน 100,000 บาท แบ่งได้ 3–4 งวด ตามหมุดหมายของงาน (เช่น จบดีไซน์ / จบระบบหลัก / ส่งมอบ) ออกใบเสร็จและใบกำกับภาษีให้ได้

ทุกแพ็กเกจรวม การแก้ไข 2 รอบ ในขั้นออกแบบ และแก้จุดย่อยได้ไม่จำกัดในขั้นพัฒนา ตราบใดที่ยังอยู่ในขอบเขตงานเดิม

ถ้าเปลี่ยนโครงสร้างหรือเพิ่มฟังก์ชันใหม่ เราจะแจ้งค่าใช้จ่ายเพิ่มให้ทราบก่อนเสมอ ไม่มีการคิดเงินย้อนหลัง

ทุกงานมีระยะรับประกัน 30 วัน หลังส่งมอบ — บั๊กที่เกิดจากงานเราแก้ให้ฟรี

หลังจากนั้นเลือกแพ็กเกจ Website Care 1,500 บาท/เดือน ได้ ซึ่งรวมการอัปเดตความปลอดภัย สำรองข้อมูล ตรวจ Uptime และโควตาแก้เนื้อหา หรือจะดูแลเองก็ได้เพราะเราส่งมอบ Source Code ให้ครบ

Scraping — เราทำเฉพาะข้อมูลที่เปิดเป็นสาธารณะ เคารพ robots.txt และเงื่อนไขการใช้งานของเว็บต้นทาง ไม่ดึงข้อมูลส่วนบุคคล ไม่หลบระบบป้องกัน และไม่ยิงถี่จนกระทบเซิร์ฟเวอร์ปลายทาง ถ้างานไหนสุ่มเสี่ยงเราจะบอกตรง ๆ และเสนอทางอื่นให้

Penetration Test — ทำได้เฉพาะระบบที่คุณเป็นเจ้าของ หรือมีหนังสืออนุญาตเป็นลายลักษณ์อักษรจากเจ้าของระบบ เราจะทำเอกสารขอบเขตและหนังสืออนุญาตให้เซ็นก่อนเริ่มงานทุกครั้ง

เซ็น NDA ได้ตั้งแต่ก่อนเริ่มคุยรายละเอียด · เราแยกสภาพแวดล้อมทดสอบออกจากข้อมูลจริง และไม่นำข้อมูลลูกค้าไปใช้นอกโปรเจกต์

ระบบที่เราสร้างออกแบบให้สอดคล้องกับ PDPA ตั้งแต่ต้น ทั้งการขอความยินยอม การเก็บเท่าที่จำเป็น และการลบข้อมูลเมื่อถูกร้องขอ
