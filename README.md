# ToroDev — เว็บไซต์

เว็บไซต์โปรโมตบริการของ ToroDev · HTML/CSS/JS ล้วน ไม่มี build step
อัปโหลดขึ้นโฮสต์แล้วใช้งานได้เลย

---

## รันบนเครื่องตัวเอง (local)

เว็บเป็น HTML/CSS/JS ล้วน ไม่ต้อง build แต่ลิงก์ทุกอันเขียนแบบ `/services.html` (นับจาก root)
จึง **ดับเบิลคลิก `index.html` ตรง ๆ ไม่ได้** หน้าจะไม่มีสไตล์และลิงก์จะพัง
ต้องเปิดผ่านเซิร์ฟเวอร์ในเครื่อง โดยให้โฟลเดอร์เว็บนี้เป็น root

### สิ่งที่ต้องมี

| อะไร | ใช้ทำอะไร | ตรวจว่ามีแล้ว |
|---|---|---|
| Git | โหลดโค้ดลงเครื่อง | `git --version` |
| Python 3 | เปิดดูหน้าเว็บทั้งหมด | `python --version` |
| PHP 8 *(ไม่บังคับ)* | ทดสอบฟอร์มติดต่อ | `php -v` |

### แบบที่ 1 — ดูหน้าเว็บ (ใช้ Python)

1. โหลดโค้ดลงเครื่อง

   ```bash
   git clone https://github.com/PleaseCompile/ToroDev.git
   cd ToroDev
   ```

   ถ้ามีโฟลเดอร์ `web` อยู่ในเครื่องแล้ว ให้ `cd` เข้าไปในโฟลเดอร์นั้นแทน

2. เช็กว่าอยู่ถูกโฟลเดอร์ ต้องเห็น `index.html` อยู่ในรายการ

   ```bash
   ls
   ```

3. เปิดเซิร์ฟเวอร์

   ```bash
   python -m http.server 8000
   ```

   บน Windows ถ้าพิมพ์ `python` แล้วเด้งไปหน้า Microsoft Store ให้ใช้ `py -m http.server 8000` แทน

4. เปิดเบราว์เซอร์ไปที่ **http://localhost:8000**

   หน้าอื่น ๆ: `/services.html` · `/pricing.html` · `/about.html` · `/contact.html`

5. หยุดเซิร์ฟเวอร์ด้วย `Ctrl+C` ในหน้าต่างที่รันอยู่

**ที่ใช้ได้:** ทุกหน้า รูป เมนู แท็บราคา FAQ และการตรวจฟอร์มฝั่งเบราว์เซอร์

**ที่ยังใช้ไม่ได้ในแบบนี้**

- **ส่งฟอร์มติดต่อ:** Python เสิร์ฟ `contact.php` เป็นไฟล์ธรรมดา ไม่ได้รันโค้ด PHP กดส่งแล้วจะได้ error 501 → ใช้แบบที่ 2
- **`.htaccess`:** เป็นของ Apache (บังคับ https, แคช, security headers) บนเครื่องจึงไม่ทำงาน และไม่ถูกบังคับ https

### แบบที่ 2 — ทดสอบฟอร์มติดต่อ (ใช้ PHP)

1. ติดตั้ง PHP (Windows)

   ```bash
   winget install PHP.PHP.8.4
   ```

   จากนั้น **ปิดแล้วเปิด terminal ใหม่** แล้วเช็กด้วย `php -v`
   (macOS: `brew install php` · Ubuntu: `sudo apt install php-cli`)

2. เข้าไปในโฟลเดอร์เว็บ แล้วเปิดเซิร์ฟเวอร์ของ PHP แทน Python

   ```bash
   php -S localhost:8000
   ```

3. เปิด **http://localhost:8000/contact.html** กรอกฟอร์มแล้วกดส่ง

4. สิ่งที่จะเห็น

   | กรอกอะไร | ผลที่ถูกต้อง |
   |---|---|
   | ข้อมูลครบ | แถบ **"ส่งไม่สำเร็จ ระบบอีเมลมีปัญหาชั่วคราว"** ปกติสำหรับบนเครื่อง เพราะไม่มีเมลเซิร์ฟเวอร์ให้ `mail()` ส่งออก |
   | ข้อมูลไม่ครบหรืออีเมลผิดรูปแบบ | แถบ **"ข้อมูลไม่ครบหรือรูปแบบไม่ถูกต้อง"** |

5. เช็กว่าฟอร์มรับข้อมูลได้จริง: `contact.php` จดข้อความลงไฟล์ก่อนส่งเมล
   ไฟล์อยู่ที่ **`../torodev-leads.log`** คือโฟลเดอร์ที่อยู่เหนือโฟลเดอร์เว็บขึ้นไป 1 ระดับ
   เปิดดูได้ด้วย `cat ../torodev-leads.log`

   ไฟล์นี้เก็บสิ่งที่คุณกรอกตอนทดสอบ ลบทิ้งได้เมื่อทดสอบเสร็จ และไม่ต้องเอาไปอัปโหลด

> บนเครื่องจะไม่เห็นแถบ "ส่งซ้ำเร็วเกินไป" เพราะระบบจดเวลาส่งเฉพาะตอนที่ส่งเมลสำเร็จ
> การทดสอบส่งเมลจริงต้องทำบนโฮสต์ (ดูหัวข้อ "อัปโหลดขึ้น Hostatom")

### แก้ไฟล์แล้วดูผล

แก้ไฟล์แล้วกด refresh ในเบราว์เซอร์ได้เลย ไม่ต้องรีสตาร์ตเซิร์ฟเวอร์
ถ้าสไตล์หรือสคริปต์ไม่เปลี่ยน ให้กด `Ctrl+F5` (ล้างแคชของหน้านั้น)

### ปัญหาที่เจอบ่อย

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| ขึ้น `Address already in use` หรือเปิดแล้วเป็นเว็บอื่น | พอร์ตนั้นมีโปรแกรมอื่นใช้อยู่ | เปลี่ยนเลขพอร์ต เช่น `python -m http.server 8123` แล้วเปิด `localhost:8123` |
| หน้าไม่มีสไตล์ ลิงก์พัง | เปิดไฟล์ตรง ๆ (`file:///...`) | เปิดผ่าน `http://localhost:8000` |
| ขึ้น `404 File not found` ทุกหน้า | รันเซิร์ฟเวอร์ในโฟลเดอร์ผิด | `cd` ให้ถึงโฟลเดอร์ที่มี `index.html` แล้วรันใหม่ |
| กดส่งฟอร์มแล้ว error 501 | ใช้เซิร์ฟเวอร์ของ Python | ใช้ `php -S` ตามแบบที่ 2 |
| ฟอนต์ไม่ตรงกับที่ออกแบบ | ฟอนต์โหลดจาก Google Fonts ต้องต่ออินเทอร์เน็ต | ต่อเน็ตแล้ว refresh |
| `php` ไม่ถูกรู้จักหลังติดตั้ง | terminal เดิมยังไม่เห็น PATH ใหม่ | ปิดแล้วเปิด terminal ใหม่ |

ข้อมูลติดต่อในหน้าเว็บ (`@torodev`, `080-000-0000`, `hello@torodev.co.th`) ยังเป็นค่าตัวอย่าง
ดูหัวข้อถัดไปก่อนนำขึ้นโฮสต์จริง

## ⚠️ ทำ 3 อย่างนี้ก่อนอัปขึ้นโฮสต์

ตอนนี้ในไฟล์ยังใช้ **ข้อมูลติดต่อตัวอย่าง** อยู่ ต้องเปลี่ยนเป็นของจริงก่อน

| ข้อมูล | ค่าตัวอย่างที่ใช้อยู่ตอนนี้ |
|---|---|
| โดเมน | `torodev.co.th` |
| LINE OA | `@torodev` |
| อีเมล | `hello@torodev.co.th` |
| อีเมลผู้ส่งของระบบ | `no-reply@torodev.co.th` |
| เบอร์โทร | `080-000-0000` |
| Facebook | `https://www.facebook.com/torodev` |

### 1. แก้ข้อมูลติดต่อ

เปิด `setup-config.py` แก้ค่าในกล่อง `NEW` ให้เป็นของจริง แล้วรัน:

```bash
python setup-config.py
```

สคริปต์จะไล่แก้ให้ทุกไฟล์ (รวม canonical, Open Graph, JSON-LD, sitemap, robots)
และสำรองไฟล์เดิมไว้ที่ `_backup/` — **ลบโฟลเดอร์ `_backup` ทิ้งก่อนอัปโหลด**

> ถ้าไม่อยากใช้สคริปต์ ก็เปิดหาแทนที่ (Find & Replace) ทีละค่าตามตารางข้างบนได้
> ระวังลำดับ: แทน `hello@torodev.co.th` และ `https://line.me/R/ti/p/@torodev`
> ให้เสร็จก่อน ค่อยแทน `torodev.co.th` กับ `@torodev`

### 2. สร้างอีเมลผู้ส่งใน cPanel

ฟอร์มติดต่อจะส่งเมลจาก `no-reply@โดเมนของคุณ` — **ต้องสร้างอีเมลนี้ก่อน**
ไม่งั้นเมลจะเข้าสแปมหรือถูกตีกลับ

`cPanel → Email Accounts → Create` แล้วตั้งชื่อ `no-reply`

### 3. ใส่รูปผลงานจริง

ในหน้าแรก ส่วน **"ผลงานที่กำลังจะขึ้น"** ยังเป็นช่องว่างรออยู่ 3 ช่อง
เปิด `index.html` หา `<!-- ┌───` แล้วทำตามคำอธิบายในคอมเมนต์

## อัปโหลดขึ้น Hostatom

### วิธีที่ง่ายที่สุด

```bash
python make-deploy-zip.py
```

จะได้ `torodev-deploy.zip` ที่มีเฉพาะไฟล์ที่ต้องขึ้นโฮสต์ (ประมาณ 770 KB)
จากนั้น:

1. `cPanel → File Manager → public_html`
2. ลบไฟล์ตัวอย่างของโฮสต์ทิ้ง (ถ้ามี เช่น `default.html`)
3. `Upload` ไฟล์ zip → คลิกขวาที่ไฟล์ → `Extract` → ลบไฟล์ zip บนโฮสต์ทิ้ง
4. **เปิด SSL**: `cPanel → SSL/TLS Status` → Run AutoSSL
   ต้องทำก่อน ไม่งั้น `.htaccess` จะบังคับ https แล้วเว็บเข้าไม่ได้
5. เข้าเว็บเช็กว่าเปิดได้ครบทั้ง 5 หน้า และลองส่งฟอร์มทดสอบ 1 ครั้ง

### ถ้าอยากอัปเองทีละไฟล์

อัปโหลดเฉพาะรายการนี้:

```
index.html      services.html    pricing.html
about.html      contact.html     404.html
contact.php     .htaccess        favicon.svg
favicon.ico     robots.txt       sitemap.xml
site.webmanifest
assets/         (ทั้งโฟลเดอร์)
```

**ห้ามอัปโหลด**: `รูปคนในทีม/`, `โลโก้และธีมการออกแบบV2/`, `_backup/`, `.claude/`,
`setup-config.py`, `make-deploy-zip.py`, `README.md` — เป็นไฟล์ต้นฉบับกับเครื่องมือ
ไม่ต้องอยู่บนเว็บ (ถ้าเผลออัปไป `.htaccess` บล็อกไว้ให้แล้ว แต่ก็ไม่ควรอัป)

## แก้เนื้อหาบ่อย ๆ ตรงไหน

| อยากแก้ | ไปที่ |
|---|---|
| ราคา | `pricing.html` (ตัวหลัก) + `index.html` (ส่วนพรีวิว) + `services.html` |
| ข้อความหน้าแรก | `index.html` |
| ประวัติทีม | `about.html` (ยาว) + `index.html` (สั้น) |
| ตัวเลือกในฟอร์ม | `contact.html` (`<select name="service">`) **และ** `contact.php` (`$SERVICE_LABELS`) — ต้องแก้ทั้งสองที่ให้ตรงกัน |
| สีแบรนด์ | `assets/css/style.css` บล็อก `:root` บรรทัดแรก ๆ |

**ราคาถูกเขียนไว้หลายที่** ถ้าจะขึ้นราคา ให้ค้นด้วยตัวเลข เช่น `5,000` แล้วไล่แก้ให้ครบทุกไฟล์
รวมถึงใน JSON-LD ที่หัวไฟล์ `index.html` และ `services.html` ด้วย (Google อ่านตรงนั้น)

## หลังเว็บขึ้นแล้ว ควรทำต่อ

1. **Google Search Console** — เพิ่มโดเมน แล้วส่ง `sitemap.xml`
2. **Google Business Profile** — ถ้ามีที่อยู่ร้าน ช่วยเรื่องค้นหาในพื้นที่มาก
3. **ติด Google Analytics 4** (ถ้าต้องการ) — วางสคริปต์ก่อน `</head>`
   จากนั้น **ต้องแก้ CSP ใน `.htaccess`** ด้วย ไม่งั้นจะถูกบล็อก:
   เติม `https://www.googletagmanager.com` เข้าไปใน `script-src`
   และ `https://www.google-analytics.com` ใน `connect-src`
4. **ทดสอบ Rich Results** — https://search.google.com/test/rich-results
5. **ทดสอบความเร็ว** — https://pagespeed.web.dev

## หมายเหตุด้านเนื้อหา

- **ราคาทั้งหมด** อ้างอิงจากช่วงราคาตลาดไทยปี 2568–2569 และวางให้ไล่ระดับกัน
  ปรับได้ตามต้นทุนจริงของทีม
- **ไม่มีชื่อลูกค้า รีวิว หรือตัวเลขผลงานที่แต่งขึ้น** ในเว็บนี้เลย
  ส่วนผลงานเป็นช่องว่างรอใส่ของจริง — เติมเมื่อขออนุญาตลูกค้าเรียบร้อยแล้ว
- **ข้อความด้านกฎหมาย** เรื่อง Scraping และ Penetration Test เขียนไว้ทั้งหน้าแรก
  หน้าบริการ และ FAQ — ไม่ควรลบออก เพราะเป็นทั้งการป้องกันตัวและจุดที่ทำให้ดูมืออาชีพ
