# ToroDev — เว็บไซต์

เว็บไซต์โปรโมตบริการของ ToroDev · HTML/CSS/JS ล้วน ไม่มี build step
อัปโหลดขึ้นโฮสต์แล้วใช้งานได้เลย

---

## ⚠️ ทำ 3 อย่างนี้ก่อนอัปขึ้นโฮสต์

ตอนนี้ในไฟล์ยังใช้ **ข้อมูลติดต่อตัวอย่าง** อยู่ ต้องเปลี่ยนเป็นของจริงก่อน

| ข้อมูล | ค่าตัวอย่างที่ใช้อยู่ตอนนี้ |
|---|---|
| โดเมน | `torodev.co.th` |
| LINE OA | `@torodev` |
| อีเมล | `hello@torodev.co.th` |
| อีเมลผู้ส่งของระบบ | `no-reply@torodev.co.th` |
| เบอร์โทร | `080-000-0000` |
| Facebook | `https://www.facebook.com/torodev` |

### 1. แก้ข้อมูลติดต่อ

เปิด `setup-config.py` แก้ค่าในกล่อง `NEW` ให้เป็นของจริง แล้วรัน:

```bash
python setup-config.py
```

สคริปต์จะไล่แก้ให้ทุกไฟล์ (รวม canonical, Open Graph, JSON-LD, sitemap, robots)
และสำรองไฟล์เดิมไว้ที่ `_backup/` — **ลบโฟลเดอร์ `_backup` ทิ้งก่อนอัปโหลด**

> ถ้าไม่อยากใช้สคริปต์ ก็เปิดหาแทนที่ (Find & Replace) ทีละค่าตามตารางข้างบนได้
> ระวังลำดับ: แทน `hello@torodev.co.th` และ `https://line.me/R/ti/p/@torodev`
> ให้เสร็จก่อน ค่อยแทน `torodev.co.th` กับ `@torodev`

### 2. สร้างอีเมลผู้ส่งใน cPanel

ฟอร์มติดต่อจะส่งเมลจาก `no-reply@โดเมนของคุณ` — **ต้องสร้างอีเมลนี้ก่อน**
ไม่งั้นเมลจะเข้าสแปมหรือถูกตีกลับ

`cPanel → Email Accounts → Create` แล้วตั้งชื่อ `no-reply`

### 3. ใส่รูปผลงานจริง

ในหน้าแรก ส่วน **"ผลงานที่กำลังจะขึ้น"** ยังเป็นช่องว่างรออยู่ 3 ช่อง
เปิด `index.html` หา `<!-- ┌───` แล้วทำตามคำอธิบายในคอมเมนต์

## อัปโหลดขึ้น Hostatom

### วิธีที่ง่ายที่สุด

```bash
python make-deploy-zip.py
```

จะได้ `torodev-deploy.zip` ที่มีเฉพาะไฟล์ที่ต้องขึ้นโฮสต์ (ประมาณ 770 KB)
จากนั้น:

1. `cPanel → File Manager → public_html`
2. ลบไฟล์ตัวอย่างของโฮสต์ทิ้ง (ถ้ามี เช่น `default.html`)
3. `Upload` ไฟล์ zip → คลิกขวาที่ไฟล์ → `Extract` → ลบไฟล์ zip บนโฮสต์ทิ้ง
4. **เปิด SSL**: `cPanel → SSL/TLS Status` → Run AutoSSL
   ต้องทำก่อน ไม่งั้น `.htaccess` จะบังคับ https แล้วเว็บเข้าไม่ได้
5. เข้าเว็บเช็กว่าเปิดได้ครบทั้ง 5 หน้า และลองส่งฟอร์มทดสอบ 1 ครั้ง

### ถ้าอยากอัปเองทีละไฟล์

อัปโหลดเฉพาะรายการนี้:

```
index.html      services.html    pricing.html
about.html      contact.html     404.html
contact.php     .htaccess        favicon.svg
favicon.ico     robots.txt       sitemap.xml
site.webmanifest
assets/         (ทั้งโฟลเดอร์)
```

**ห้ามอัปโหลด**: `รูปคนในทีม/`, `โลโก้และธีมการออกแบบV2/`, `_backup/`, `.claude/`,
`setup-config.py`, `make-deploy-zip.py`, `README.md` — เป็นไฟล์ต้นฉบับกับเครื่องมือ
ไม่ต้องอยู่บนเว็บ (ถ้าเผลออัปไป `.htaccess` บล็อกไว้ให้แล้ว แต่ก็ไม่ควรอัป)

## แก้เนื้อหาบ่อย ๆ ตรงไหน

| อยากแก้ | ไปที่ |
|---|---|
| ราคา | `pricing.html` (ตัวหลัก) + `index.html` (ส่วนพรีวิว) + `services.html` |
| ข้อความหน้าแรก | `index.html` |
| ประวัติทีม | `about.html` (ยาว) + `index.html` (สั้น) |
| ตัวเลือกในฟอร์ม | `contact.html` (`<select name="service">`) **และ** `contact.php` (`$SERVICE_LABELS`) — ต้องแก้ทั้งสองที่ให้ตรงกัน |
| สีแบรนด์ | `assets/css/style.css` บล็อก `:root` บรรทัดแรก ๆ |

**ราคาถูกเขียนไว้หลายที่** ถ้าจะขึ้นราคา ให้ค้นด้วยตัวเลข เช่น `5,000` แล้วไล่แก้ให้ครบทุกไฟล์
รวมถึงใน JSON-LD ที่หัวไฟล์ `index.html` และ `services.html` ด้วย (Google อ่านตรงนั้น)

## หลังเว็บขึ้นแล้ว ควรทำต่อ

1. **Google Search Console** — เพิ่มโดเมน แล้วส่ง `sitemap.xml`
2. **Google Business Profile** — ถ้ามีที่อยู่ร้าน ช่วยเรื่องค้นหาในพื้นที่มาก
3. **ติด Google Analytics 4** (ถ้าต้องการ) — วางสคริปต์ก่อน `</head>`
   จากนั้น **ต้องแก้ CSP ใน `.htaccess`** ด้วย ไม่งั้นจะถูกบล็อก:
   เติม `https://www.googletagmanager.com` เข้าไปใน `script-src`
   และ `https://www.google-analytics.com` ใน `connect-src`
4. **ทดสอบ Rich Results** — https://search.google.com/test/rich-results
5. **ทดสอบความเร็ว** — https://pagespeed.web.dev

## หมายเหตุด้านเนื้อหา

- **ราคาทั้งหมด** อ้างอิงจากช่วงราคาตลาดไทยปี 2568–2569 และวางให้ไล่ระดับกัน
  ปรับได้ตามต้นทุนจริงของทีม
- **ไม่มีชื่อลูกค้า รีวิว หรือตัวเลขผลงานที่แต่งขึ้น** ในเว็บนี้เลย
  ส่วนผลงานเป็นช่องว่างรอใส่ของจริง — เติมเมื่อขออนุญาตลูกค้าเรียบร้อยแล้ว
- **ข้อความด้านกฎหมาย** เรื่อง Scraping และ Penetration Test เขียนไว้ทั้งหน้าแรก
  หน้าบริการ และ FAQ — ไม่ควรลบออก เพราะเป็นทั้งการป้องกันตัวและจุดที่ทำให้ดูมืออาชีพ

## รันดูในเครื่องก่อน

```bash
python -m http.server 8899
```

แล้วเปิด http://localhost:8899

> ฟอร์มติดต่อจะยังส่งไม่ได้ เพราะ `python -m http.server` รัน PHP ไม่ได้
> ถ้าอยากทดสอบฟอร์มด้วย ให้ใช้ `php -S 127.0.0.1:8899` แทน (ต้องมี PHP ในเครื่อง)
