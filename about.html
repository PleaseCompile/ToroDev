About

ทีมเล็ก ที่ประกอบ
ให้ครบสายตั้งแต่วันแรก

ToroDev ไม่ได้ตั้งขึ้นมาเพื่อรับงานให้ได้เยอะที่สุด แต่ตั้งขึ้นเพราะเราเบื่อการเห็นเว็บที่ทำเสร็จสวยแล้วพังภายในสามเดือน เลยเลือกจะมีทั้งคนทดสอบและคนดูความปลอดภัยอยู่ในทีม ตั้งแต่ก่อนจะมีลูกค้าคนแรก

Our Take

งานที่พัง
มักไม่ได้พังที่โค้ด

เว็บที่ลูกค้าเอามาให้เราซ่อม ส่วนใหญ่ไม่ได้พังเพราะเขียนโค้ดไม่เป็น แต่พังเพราะไม่มีใครทดสอบเคสที่ผู้ใช้ทำผิด ไม่มีใครดูว่าฟอร์มนั้นยิงข้อมูลอะไรออกไปบ้าง และไม่มีใครกลับมาดูมันอีกเลยหลังวันส่งมอบ

เราเลยออกแบบทีมให้มีคนรับผิดชอบสามเรื่องที่มักถูกข้าม — ทดสอบ, ความปลอดภัย และ การดูแลต่อ ไม่ใช่เพราะอยากขายของเพิ่ม แต่เพราะถ้าไม่มีสามอย่างนี้ งานที่ส่งไปก็แค่รอวันมีปัญหา

The Team

ห้าคน ห้าหน้าที่

งานของคุณจะผ่านมือทั้งห้าคนนี้ตามลำดับ ไม่มีใครทำงานทับกัน และไม่มีขั้นตอนไหนถูกข้ามเพราะ “ไม่มีคนทำ”

01 / 05

ลมเหนือ

Cyber Security

ดูแลความปลอดภัยของทุกงานก่อนขึ้นใช้จริง ตรวจช่องโหว่ตามแนวทาง OWASP Top 10 ทั้งการสแกนอัตโนมัติและทดสอบด้วยมือ แล้วสรุปเป็นรายงานที่ระบุระดับความเสี่ยง ขั้นตอนทำซ้ำ และวิธีแก้ที่ทีมพัฒนาเอาไปทำต่อได้ทันที นอกจากงานภายในแล้วยังรับงาน Penetration Test และ Vulnerability Assessment ให้ลูกค้าภายนอกด้วย

02 / 05

บอย ปิยะ

Full Stack Developer

เขียนทั้งหน้าบ้านและหลังบ้าน ตั้งแต่เว็บไซต์ทั่วไป ระบบ ERP/CRM ไปจนถึง LIFF App บน LINE ถนัดงานที่ต้องเชื่อม API หลายระบบเข้าด้วยกัน และงานที่ต้องย้ายข้อมูลเดิมจาก Excel หรือระบบเก่าเข้าสู่ระบบใหม่โดยไม่ให้ข้อมูลหาย รวมถึงงาน Automation และ Data Pipeline

03 / 05

ต๊ะ

UX / UI Designer

เริ่มจากคำถามว่า “คนที่เข้ามาต้องการอะไร” ก่อนจะลงมือวางโครงหน้า ออกแบบใน Figma พร้อม Prototype ที่กดได้จริงเพื่อให้ลูกค้าเห็นภาพก่อนเขียนโค้ด ให้ความสำคัญกับการอ่านง่ายบนจอมือถือ ขนาดปุ่มที่กดไม่พลาด และเส้นทางที่พาไปสู่การตัดสินใจ

04 / 05

อาร์ต

QA Tester

หน้าที่คือทำให้งานพังตั้งแต่ก่อนถึงมือลูกค้า ไล่ทดสอบทุกฟังก์ชันทั้งเคสปกติและเคสที่ผู้ใช้กดผิด ทดสอบข้ามเบราว์เซอร์และอุปกรณ์จริง ตรวจฟอร์ม การแจ้งเตือน และเส้นทางการชำระเงิน ทุกข้อที่เจอถูกบันทึกเป็นรายการให้ทีมแก้ แล้วทดสอบซ้ำจนผ่านถึงจะปล่อยงาน

05 / 05

วิน

Graphic Designer

ดูแลงานภาพทั้งหมดของโปรเจกต์ ตั้งแต่โลโก้ แบนเนอร์ ภาพประกอบ Rich Menu บน LINE ไปจนถึงชุดเทมเพลตคอนเทนต์สำหรับโซเชียลที่ทีมลูกค้าเอาไปแก้ใช้เองต่อได้ ทำงานบนระบบแบรนด์ที่วางไว้ เพื่อให้ทุกชิ้นงานที่ออกไปดูเป็นชุดเดียวกัน

How we work

หกข้อที่เรายึด
ไม่ว่างานจะเล็กหรือใหญ่

ไม่ใช่คำสวย ๆ ติดผนัง แต่เป็นข้อตกลงที่เราใช้ตัดสินใจจริงเวลามีเรื่องต้องเลือก

01

บอกราคาก่อน ไม่ให้ต้องทัก

ราคาทุกบริการเปิดไว้บนเว็บ ถ้างานของคุณแพงกว่าราคาเริ่มต้น เราบอกเหตุผลตั้งแต่รอบแรก ไม่ใช่ค่อยมาแจ้งตอนงานเดินไปครึ่งทางแล้ว

02

ทดสอบก่อนส่ง ทุกงาน ไม่มีข้อยกเว้น

ต่อให้เป็นเว็บ 4 หน้าราคา 5,000 บาท ก็ผ่าน QA Tester และการตรวจช่องโหว่เหมือนกับงานหลักแสน เพราะช่องโหว่ไม่ได้เลือกว่าเว็บนั้นราคาเท่าไหร่

03

งานเป็นของลูกค้า ไม่ใช่ของเรา

ส่งมอบ Source Code ไฟล์ออกแบบ และบัญชีทั้งหมด ทุกอย่างอยู่ในชื่อคุณ ถ้าวันหนึ่งอยากเปลี่ยนทีม ก็ย้ายไปได้เลยโดยไม่ต้องมาขออะไรจากเรา

04

ปฏิเสธงานที่ไม่ควรรับ

ถ้างานไหนสุ่มเสี่ยงผิดกฎหมาย ผิดเงื่อนไขแพลตฟอร์ม หรือเราทำได้ไม่ดีพอ เราจะบอกตรง ๆ และแนะนำทางเลือกอื่นให้ ดีกว่ารับมาแล้วส่งงานที่ไม่ควรส่ง

05

อธิบายให้เข้าใจ ไม่ใช่ทำให้ดูยาก

เราไม่ใช้ศัพท์เทคนิคเพื่อให้ดูเก่ง ทุกอย่างที่เสนอจะอธิบายได้ว่าทำไปทำไม ช่วยธุรกิจตรงไหน และถ้าไม่ทำจะเป็นอะไรไหม

06

ไม่หายไปหลังวันส่งมอบ

ทุกงานมีระยะรับประกัน และมีแพ็กเกจดูแลต่อให้เลือก ไม่ใช่บังคับ แต่ถ้าคุณต้องการ เราอยู่ตรงนี้ ไม่ใช่ต้องตามหาในแชตเก่าเมื่อปีที่แล้ว
